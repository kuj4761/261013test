# 🎙️ SpeakWise (스피크와이즈) - AI 영어 회화 & 실시간 문장 첨삭 튜터

> **자연스러운 대화로 배우는 실전 영어 회화와 실시간 원어민 문장 첨삭 웹 애플리케이션**

---

## 🌟 핵심 기능 소개

### 1. 🤖 AI 튜터 롤플레잉 회화
- **다양한 실전 상황(Scenarios)**: 카페 주문, 공항 입국심사, 해외 취업 영어 면접, 호텔 체크인 & 요청, 쇼핑 & 환불/교환, 일상 프리토킹
- **상황별 학습 미션(Missions)**: 필수 표현과 키워드를 연습할 수 있는 단계별 퀘스트
- **AI 튜터 성향(Persona) 설정**:
  - `Emma`: 친절하고 용기를 북돋워 주는 미국인 친구
  - `David`: 세련되고 격식 있는 비즈니스 멘토
  - `Sarah`: 문법과 뉘앙스를 꼼꼼하게 교정해 주는 철저한 튜터

### 2. ✍️ 실시간 원어민 문장 첨삭 & 교정 (Live Feedback)
- **단어 단위 시각적 Diff 비교**: 내가 말한 문장 원문과 자연스러운 원어민 표현의 차이를 하이라이트로 직관적 비교
- **한국인 빈출 콩글리시 & 비문 자동 분석**: "I am agree" → "I agree", "went to there" → "went there", "have a promise" → "have plans" 등 즉시 교정
- **뉘앙스 및 문법 해설**: 왜 원어민은 그렇게 말하는지 친절한 한국어 해설 제공
- **문장 완성도 점수 (60~100점)** 및 피드백 태그

### 3. 🎙️ Web Speech API 기반 음성 인식 (STT) & 발음 청취 (TTS)
- **마이크 버튼 클릭 한 번으로 음성 발화 (STT)**: 소리 내어 말하면서 스피킹 훈련
- **원어민 발음 듣기 (TTS)**: 미국(US), 영국(UK), 호주(AU) 억양 및 0.7x ~ 1.3x 재생 속도 조절
- **자동 재생 모드**: AI 응답 시 원어민 목소리로 자동 청취

### 4. 🗂️ 나만의 단어장 & 간격 반복(SRS) 플래시카드
- 첨삭받은 좋은 표현을 원터치로 단어장에 저장
- 3D 뒤집기 카드 애니메이션 & SRS 알고리즘 (망각곡선 주기 복습)
- 복습 필요 카드 / 완전 정복 카드 필터링

### 5. 📊 학습 통계 & 동기부여 (Gamification)
- 연속 학습 일수 (Streak)
- 누적 발화 문장 수 및 받은 첨삭 수
- 경험치(XP) 및 레벨 성장 시스템
- 일일 학습 목표 진행률 게이지

### 6. ⚡ 하이브리드 AI 엔진 (Google Gemini API 연동 + 오프라인 시뮬레이션)
- **오프라인 스마트 시뮬레이션 모드**: API 키가 없어도 모든 시나리오와 첨삭 기능이 100% 작동
- **Google Gemini API 라이브 연동**: 무료 발급받은 Gemini API 키를 [설정] 창에 입력하면 최신 AI 모델(`gemini-1.5-flash`, `gemini-2.0-flash` 등)과 무제한 자유 대화 및 정밀 첨삭 가능 (키는 브라우저 `localStorage`에만 안전 보관)

## 🚀 실행 방법

### 방법 1. 브라우저에서 바로 열기 (설치 필요 없음)
1. 바탕 화면의 `까마귀` 폴더를 엽니다.
2. `index.html` 파일을 더블 클릭하여 Chrome, Edge 등의 최신 브라우저로 실행합니다.
3. 마이크 권한 요청이 뜨면 "허용"을 누르면 즉시 음성 대화가 가능합니다!

---

## 🛠️ 기술 스택
- **프론트엔드**: HTML5, Vanilla JavaScript (ES6+ Modules), Tailwind CSS (CDN), Lucide Icons
- **음성 기술**: Web Speech API (`SpeechRecognition`, `SpeechSynthesis`)
- **데이터 보관**: HTML5 `localStorage` (서버 없이 사용자 기기에 안전 보관)
- **AI 엔진**: Google Gemini API (`v1beta / gemini-1.5-flash`) + 로컬 스마트 휴리스틱 엔진
