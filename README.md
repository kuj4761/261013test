# 📱 토익 & 비즈니스 영어 단어 학습 앱 (Voca Master PWA)

토익(TOEIC) 고득점 및 비즈니스 실무 영어 마스터를 위한 모바일 친화적 **PWA(Progressive Web App)** 단어 학습 애플리케이션입니다.

---

## 🚀 빠른 시작 방법

### 방법 1. 더블 클릭으로 바로 실행 (권장)
- 폴더 내 **`run.bat`** 파일을 더블 클릭하면 로컬 서버가 시작되고 브라우저가 자동으로 열립니다 (`http://localhost:8080`).
- 로컬 서버 모드에서는 **PWA 오프라인 캐싱 및 스마트폰 홈 화면 추가 기능**이 완벽하게 지원됩니다.

### 방법 2. 브라우저에서 바로 열기
- **`index.html`** 파일을 더블 클릭하여 Chrome, Edge, Safari 등 원하는 브라우저에서 즉시 실행할 수 있습니다. (별도 설치 필요 없음)

## ✨ 핵심 기능 소개

### 1. 🗂️ 3D 플래시카드 & 원어민 발음 (TTS)
- **카드 뒤집기**: 화면을 탭하거나 키보드 **`Space`** 바를 눌러 앞면(단어, 품사, 발음기호)과 뒷면(한글 뜻, 비즈니스 실무 예문, 연어 팁)을 확인합니다.
- **원어민 발음**: 🔊 버튼을 누르거나 키보드 **`V`** 키를 눌러 Web Speech API 원어민 발음을 즉시 재생합니다.
- **간격 반복 평가**:
  - `✓ 완벽히 외움` (오른쪽 화살표 `→` 또는 오른쪽 스와이프): Leitner 상자 레벨 업 (복습 주기 연장)
  - `❌ 아직 헷갈림` (왼쪽 화살표 `←` 또는 왼쪽 스와이프): 1단계로 강등되어 내일 다시 집중 복습

### 2. 🎯 인터랙티브 퀴즈 모드
- **4지선다 뜻 맞히기**: 영어 단어를 보고 정확한 한글 뜻을 선택
- **4지선다 단어 맞히기**: 한글 뜻을 보고 적절한 영어 단어를 선택
- **스펠링 타이핑 테스트**: 첫 글자 힌트와 품사를 보고 철자를 직접 입력하여 철자 암기력 극대화
- 실시간 시각 피드백 및 Web Audio 사운드 효과음

### 3. 🧠 에빙하우스 간격 반복 (Spaced Repetition / Leitner 5단계)
- **Box 1 (1일 주기)**: 신규 및 헷갈린 단어
- **Box 2 (2일 주기)**: 1차 암기 성공 단어
- **Box 3 (4일 주기)**: 중기 기억 단어
- **Box 4 (7일 주기)**: 장기 기억 전환 단계
- **Box 5 (14일 주기)**: 완전 정복(마스터) 단어
- 대시보드에서 매일 복습 주기에 도달한 단어 수와 5단계 분포 현황을 한눈에 파악할 수 있습니다.

### 4. 📚 나만의 단어장 & Excel(CSV) 연동
- 비즈니스/토익 실무 핵심 80여 개 엄선 단어가 기본 탑재되어 있습니다.
- **새 단어 추가/수정/삭제**: 사용자가 직접 단어, 뜻, 예문, 팁을 자유롭게 등록 가능
- **Excel/CSV 가져오기/내보내기**: 엑셀에서 정리한 단어장을 CSV 파일로 한 번에 업로드하거나 현재 단어장을 엑셀용 CSV 파일로 다운로드
- **JSON 백업/복원**: 학습 진도 및 연속 학습 기록(Streak) 전체 백업 지원

### 5. 📱 모바일 홈 화면 추가 (PWA 앱 설치)
- **스마트폰/태블릿(Chrome/Safari)**:
  - 브라우저 메뉴(공유 또는 점 3개 메뉴)에서 **"홈 화면에 추가"** 또는 **"앱 설치"**를 선택하면 일반 모바일 앱처럼 독립 창으로 실행됩니다.
  - 서비스 워커(Service Worker)가 탑재되어 있어 인터넷 연결이 불안정하거나 오프라인 상태에서도 학습이 가능합니다.

## ⌨️ 키보드 단축키 (PC 환경)

| 단축키 | 동작 |
| :--- | :--- |
| **`Space`** | 플래시카드 앞/뒤 뒤집기 |
| **`→` (오른쪽 방향키)** | 단어 외움 (Level Up) |
| **`←` (왼쪽 방향키)** | 아직 헷갈림 (Box 1 재학습) |
| **`V` 또는 `P`** | 원어민 영어 발음 듣기 (TTS) |

## 📂 프로젝트 파일 구조

```
메추라기/
├── index.html        # 메인 웹 애플리케이션 화면
├── manifest.json     # PWA 앱 설정 (아이콘, 테마 등)
├── sw.js             # PWA 오프라인 캐싱 서비스 워커
├── run.bat           # 윈도우 원클릭 실행 배치 파일
├── server.ps1        # 초경량 로컬 웹 서버 스크립트
├── README.md         # 사용 설명서
├── css/
│   └── style.css     # 모던 UI, 다크모드, 3D 플래시카드 애니메이션 스타일
├── js/
│   ├── data.js       # 토익 & 비즈니스 실무 단어 데이터셋
│   ├── storage.js    # 로컬 저장소, 간격 반복(Leitner), CSV/JSON 변환기
│   ├── tts.js        # Web Speech 발음 및 Web Audio 효과음 엔진
│   └── app.js        # 네비게이션, 퀴즈, 단어장, 통계 제어 컨트롤러
└── icons/
    ├── icon-192.png  # PWA 아이콘 (192x192)
    └── icon-512.png  # PWA 아이콘 (512x512)
```
